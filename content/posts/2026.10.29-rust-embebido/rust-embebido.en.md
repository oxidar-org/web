## Why Rust for embedded systems?

Embedded systems are everywhere: satellites, medical equipment, sensors, cars, home appliances. This is software that runs directly on a microcontroller, without an operating system, with little memory, and where a bug can cost far more than a reboot.

That's where Rust has a lot to offer. With `#![no_std]` we leave the standard library behind and stick with `core`: the same language, the same memory safety guarantees, and the same type system, but running on bare metal. No garbage collector, no runtime, and with the compiler watching out for the kinds of errors that in C usually only show up in the field.

In this workshop we'll take our first steps in that world.

## Two venues, one day

We're organizing this event together with two local teams who will run each venue:

- **Bariloche**: run by a team from **INVAP**. Location to be confirmed.
- **Santa Fe**: run by the **Universidad Nacional del Litoral**. Building to be confirmed.

From **Oxidar.org** we coordinate the event and provide online support to both venues throughout the day.

## What will the day look like?

The format is similar to the [hackathon we held in Buenos Aires](/snakear-recap/):

1. **Welcome**: introductions and how the day will work.
2. **Learning session** (about an hour): what it's like to program in Rust without an operating system, what changes with `no_std`, and how to talk to a microcontroller.
3. **Hands-on**: we'll work with a **starter kit prepared by INVAP**, designed for those who are just getting started with the embedded world.
4. **The classic Oxidar quiz**: because there's no event without a Rust trivia.

> **Note:** no prior experience with electronics or microcontrollers is required. The workshop is designed so that anyone who programs in Rust (or wants to get started) walks away with something new.
